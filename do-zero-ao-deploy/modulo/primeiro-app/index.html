Seu primeiro app, do começo ao fim

Um caderno de cafés feito com o método do spec: versões com Git, dados salvos no navegador e um link no ar.

5 aulas · 110 min

Quero saber quando abrirVer as aulas

O que você vai construir

Antes dos projetos grandes, um app pequeno do começo ao fim: um caderno de cafés onde você anota os lugares que visitou, dá uma nota, filtra e apaga, e tudo continua lá quando você reabre a página. Você usa o método do spec, salva cada passo com Git, entende o padrão que está por trás de quase todo app e termina com o app no ar, num link que abre em qualquer celular.

  • Um app inteiro, pequenoTermina numa sentada, e usa tudo o que você viu nos fundamentos.
  • Git desde o começoCada passo salvo numa versão. Se a IA estragar algo, você volta em segundos.
  • O padrão de todo appDados, uma função que desenha a tela e eventos que mudam os dados. O mesmo dos projetos grandes.

O que você vai aprender

  • Escrever o spec de um app pequeno e construir passo a passo
  • Salvar versões com Git e desfazer uma mudança ruim
  • Desenhar a tela a partir de uma lista de dados
  • Formulários, botões de apagar e filtros
  • Guardar dados no navegador com localStorage e JSON
  • Publicar de graça no GitHub Pages, com um link para compartilhar

As aulas

0 de 5 aulas concluídas
  1. 1O Caderno de cafés, spec e primeiro passoConheça o app pequeno que você vai construir do começo ao fim, escreva o spec e o CLAUDE.md com o método do spec e faça o primeiro passo funcionar.🔒
  2. 2Salvando versões com GitO Git como seus pontos de salvamento. Transforme o projeto num repositório, salve uma versão depois de cada passo, leia o histórico e desfaça uma mudança que deu errado.🔒
  3. 3Dados, estado e a telaO padrão por trás de quase todo app. Os dados numa lista, uma função que desenha a tela a partir deles e eventos que mudam os dados e desenham de novo.🔒
  4. 4Guardando dados com localStorageGuarde dados no navegador para eles sobreviverem a um recarregamento, transforme listas em texto com JSON, veja tudo no DevTools, saiba o que não guardar ali e termine o Caderno de cafés.🔒
  5. 5Publicando o Caderno de cafés no GitHub PagesMande o seu repositório para o GitHub, transforme ele num site público e grátis com o GitHub Pages, conserte o bug clássico da primeira publicação e atualize o site a cada push.🔒
