2.2 Funções, as receitas do código

O que é uma função, como passar dados para ela, o que o return faz e por que a IA divide tudo em funções.

⏱ 20 min

Uma função é uma receita

Uma função é um pedaço de código com nome, que você escreve uma vez e usa quantas vezes quiser. Pense numa receita:

  • Ingredientes: os dados que você passa para ela (os parâmetros).
  • Modo de preparo: o código dentro das chaves { }.
  • O prato pronto: o que ela devolve com return.

Rode o exemplo abaixo. O que aparece no console é o que o código mostra com console.log.

Por que usar funções

Imagine calcular quanto tempo se leva a pé até cada café de uma lista. Sem função, você repetiria a mesma conta em todo lugar. Com função, a conta fica num lugar só, com um nome que explica o que ela faz:

  2. Agora a pessoa vai de bicicleta, a 15 km/h. Em vez de copiar a função, dê a ela um segundo parâmetro: function minutosAte(km, velocidade), e troque o 5 por velocidade. Teste com minutosAte(0.96, 15).

Foi isso que você acabou de fazer: transformar uma função específica numa função mais útil, só trocando um número fixo por um parâmetro.

return: devolver não é mostrar

O erro de iniciante mais comum: a função faz a conta, mas não devolve. Sem return, a função termina e o resultado some. Quem chamou recebe undefined (algo como “não tem nada aqui”).

Ache o bug

O total deveria ser 80, mas aparece undefined. Qual linha tem o problema?

Clique na linha que tem o problema.

console.log só mostra um valor no console, para você ver. return entrega o valor para quem chamou a função, para o código continuar usando.

Agora é com você. Escreva o código no editor e clique em Testar: os testes conferem cada parte e dizem o que falta.

Onde você vai ver isso no curso

  • No jogo 3D, a função alturaEm(x, z) recebe um ponto do mapa e devolve a altura do chão ali. O terreno inteiro e a colisão usam a mesma função.
  • No app de mapa, uma função recebe duas posições e devolve a distância entre elas, para ordenar os cafés do mais perto ao mais longe.
  • No botão do “Olá, mundo!”, o código que roda a cada clique é uma função. Você vê isso na aula sobre eventos.
💡
Peça funções pequenas para a IA

Código bom é feito de funções pequenas, cada uma com uma tarefa e um nome claro. Quando um arquivo ficar confuso, peça: “Divida este código em funções pequenas, com nomes que digam o que cada uma faz. Não mude o comportamento.” E quando não entender uma função: “Explique esta função em português simples: o que ela recebe, o que faz e o que devolve.”
