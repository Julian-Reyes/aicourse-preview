1.2 Terminal sem medo

Os cinco comandos que você precisa para trabalhar com o Claude Code, praticados num terminal de treino direto na página.

⏱ 15 min

Por que o terminal

O Claude Code mora no terminal. Você não precisa virar especialista: com cinco comandos você já se vira em todos os projetos deste curso. Eles servem para responder duas perguntas: “onde eu estou?” e “como chego na pasta do meu projeto?”.

Duas ideias antes dos comandos

1. O terminal está sempre “dentro” de uma pasta. É a pasta atual. Quando você abre o Claude Code, ele trabalha nos arquivos da pasta atual. Por isso entrar na pasta certa antes de rodar claude é tão importante. Os outros agentes que você vai ver na próxima aula, codex e copilot, funcionam do mesmo jeito.

2. Caminhos têm atalhos.

Atalho Significa
~ Sua pasta inicial (no Mac, /Users/seu-nome)
.. A pasta “de cima”, um nível acima
. A própria pasta atual
Documents/projetos A pasta projetos dentro de Documents

Os cinco comandos

Comando O que faz
pwd Mostra em qual pasta você está
ls Lista o que tem na pasta
cd pasta Entra numa pasta (cd .. volta uma)
mkdir nome Cria uma pasta
touch nome Cria um arquivo vazio

Pratique aqui

Este terminal é de mentira: nada do que você digitar mexe no seu computador. Cumpra as missões ao lado. Se errar, sem problema, é para isso que ele existe.

Terminal de treino

Pratique sem medo: nada aqui mexe no seu computador

Digite um comando e aperte Enter. Digite help para ver a lista.
voce@mac ~ %
Missões
  1. 1Descubra onde você está: pwd
  2. 2Veja o que tem aqui: ls
  3. 3Entre na pasta Documents
  4. 4Crie uma pasta chamada meus-projetos
  5. 5Entre em meus-projetos
  6. 6Crie um arquivo index.html
  7. 7Volte uma pasta com cd ..
  8. 8Leia a lista de compras: cat lista-de-compras.txt

Dicas que economizam tempo

  • Tab completa nomes. Digite cd Doc e aperte Tab: o terminal completa para Documents.
  • Seta para cima repete os comandos anteriores.
  • Arraste uma pasta do Finder ou do Explorer para dentro do terminal: o caminho completo aparece digitado.
  • Evite espaços nos nomes. Use meu-app em vez de meu app. Espaços complicam a vida no terminal.
  • No VS Code, abra a pasta do projeto e use Terminal → New Terminal: o terminal já abre dentro da pasta certa.
💡
No Windows (PowerShell)

pwd, ls, cd, mkdir e cat funcionam igual. O touch não existe: para criar um arquivo vazio, use ni index.html (abreviação de New-Item).
