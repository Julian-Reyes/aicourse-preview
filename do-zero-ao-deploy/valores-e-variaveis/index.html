2.1 Valores e variáveis, as caixas com etiqueta

Os tipos de valor que aparecem em todo app, como guardar um valor com nome, a diferença entre const e let e como montar textos.

⏱ 15 min

Todo programa mexe com valores

Tudo o que um app guarda e mostra é um valor: o nome de um café, uma distância, se ele está aberto ou não. Os três tipos que você mais vai ver:

  • Texto (a IA chama de string): sempre entre aspas, como 'Café da Praça'.
  • Número: sem aspas, como 42 ou 0.2. Em código, a vírgula decimal é um ponto.
  • Verdadeiro ou falso (boolean): true ou false. Toda comparação, como 5 > 3, dá um desses dois.

Rode o exemplo. Cada console.log mostra um valor no console, embaixo do código.

Experimente

Três tipos de valor

Console
Nada no console ainda. Use console.log(...) para mostrar valores aqui.

Desafio: acrescente as linhas console.log('2' + '2') e console.log(2 + 2). Os resultados são diferentes porque o primeiro par é texto: o + cola um texto no outro, e '2' + '2' vira '22'. Esse detalhe causa bugs de verdade, por exemplo quando um número digitado num formulário chega como texto.

Uma variável é uma caixa com etiqueta

Uma variável guarda um valor com um nome, para você usar depois. Pense numa caixa com uma etiqueta: a etiqueta é o nome, e o que está dentro é o valor.

Experimente

Suas primeiras variáveis

Console
Nada no console ainda. Use console.log(...) para mostrar valores aqui.

Desafio: crie uma variável nota com o valor 4.5 e mostre no console com console.log('Nota:', nota).

const ou let?

Você deve ter reparado que o exemplo usa duas palavras para criar variáveis:

  • const para valores que não mudam depois de criados, como o nome do café.
  • let para valores que vão mudar, como o número de visitas.

A IA usa const quase sempre e let só quando precisa. Isso ajuda a ler o código: quando você vê let, sabe que aquele valor muda em algum lugar.

Ache o bug

O console mostra o erro “Assignment to constant variable” na linha 3. Qual linha precisa mudar?

Clique na linha que tem o problema.

Agora é com você. Escreva o código no editor e clique em Testar: os testes conferem cada parte e dizem o que falta.

Qual é o tipo?

Separe

Texto, número ou verdadeiro/falso?

  • 'Ana'
  • 42
  • '42'
  • true
  • 'true'
  • 0.5
  • 5 > 3

Onde você vai ver isso no curso

  • No jogo 3D, let passados = 0 conta quantos anéis você atravessou, e let inicio = performance.now() guarda a hora em que a corrida começou. São let porque mudam durante o jogo.
  • No app de mapa, let voce = [-18.9186, -48.2772] guarda a sua posição (latitude e longitude). Ela muda quando o navegador descobre onde você está.
  • No app com IA, o servidor guarda em const TIPOS_ACEITOS os tipos de foto que aceita. Essa lista nunca muda enquanto o app roda.
  • No botão do “Olá, mundo!”, let indice = 0 lembra qual cor está no fundo agora.
💡
Bons nomes valem ouro

Uma variável chamada x não diz nada. Uma chamada minutosAPe diz tudo. Quando a IA escrever nomes confusos, peça: “Renomeie as variáveis deste arquivo para nomes que expliquem o que elas guardam. Não mude o comportamento.” E quando não entender uma: “O que a variável indice guarda, e em que lugares do código ela muda?”
