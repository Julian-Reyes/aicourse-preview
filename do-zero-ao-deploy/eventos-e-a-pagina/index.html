Eventos e a página, fazendo os cliques funcionarem

Como o JavaScript encontra um elemento da página, muda o texto dele e reage a cliques e ao que a pessoa digita.

⏱ 20 min

A página é feita de elementos

Até agora o código só falava com o console. Num app de verdade, ele muda a página: troca um texto, mostra um número, pinta o fundo. A página é feita de elementos escritos em HTML, como <h1> (um título), <p> (um parágrafo) e <button> (um botão).

Para o JavaScript mexer num elemento, primeiro ele precisa encontrá-lo. O jeito mais comum é dar um id (um nome único) ao elemento no HTML e procurar por ele com document.getElementById:

Desafio: troque também o texto do parágrafo. Ele tem o id info.

addEventListener: “quando isso acontecer, faça aquilo”

Uma página que muda sozinha não serve muito. O que importa é reagir ao que a pessoa faz: um clique, uma tecla, um texto digitado. Cada uma dessas coisas é um evento. E addEventListener diz: quando este evento acontecer neste elemento, rode esta função.

Clique no botão algumas vezes. Repare que a função não roda quando a página abre: ela fica esperando, e roda uma vez a cada clique. É uma arrow function, igual às da aula de funções.

Desafios:

  1. Acrescente um botão para zerar. No HTML: <button id="zerar">Zerar</button>. No JavaScript, um segundo addEventListener nesse botão que põe visitas = 0 e atualiza o contador.
  2. Quando as visitas chegarem a 5, mostre “Ganhou um café grátis!” no console. Você precisa de um if dentro da função do clique.

O “Olá, mundo!” de novo

Lembra do botão que muda a cor do fundo, do primeiro módulo? Agora você consegue ler cada linha dele:

Experimente

Olá, mundo!

Resultado
  • const cores = [...] é uma lista de cores.
  • let indice = 0 é uma variável que muda: guarda a posição da cor atual.
  • addEventListener('click', () => { ... }) é um evento que roda uma função a cada clique.
  • indice = (indice + 1) % cores.length soma 1, e o % (o resto da divisão) faz a conta voltar a 0 depois da última cor.
  • document.body.style.background = cores[indice] pega a cor daquela posição e pinta o fundo.

Desafios:

  1. Acrescente uma cor nova à lista, por exemplo '#c7d2fe'. Nada mais precisa mudar, porque o código usa cores.length.
  2. Faça o título mudar também. No HTML, dê um id ao título: <h1 id="titulo">. No JavaScript, dentro do clique, mude o textContent dele para `Cor ${indice + 1} de ${cores.length}`.

O botão que não faz nada

Este é o bug que você mais vai encontrar no começo: você clica, e nada acontece.

Ache o bug

Clicar no botão não faz nada, e o console mostra “Cannot read properties of null (reading 'addEventListener')”. Qual linha tem o problema?

Clique na linha que tem o problema.

Onde você vai ver isso no curso

  • No jogo 3D, os eventos keydown e keyup dizem quando uma tecla foi apertada e solta. O jogo guarda isso num objeto, teclas[e.code] = true, e a cada quadro confere quais setas estão apertadas. No celular, os botões na tela usam o evento pointerdown para fazer o mesmo.
  • No app de mapa, os botões de check-in ficam dentro dos balõezinhos do mapa. Em vez de pôr um evento em cada botão, o app escuta os cliques da página inteira com document.addEventListener('click', ...) e confere qual botão foi clicado.
  • No app com IA, o campo de escolher foto usa o evento change (escrito como onchange), que acontece quando a pessoa escolhe um arquivo.
💡
Quando um botão não faz nada

Abra o console (no navegador, F12 ou clique direito → Inspecionar → Console) e veja se tem um erro em vermelho. Copie o erro e mande para a IA junto com o contexto: “Este botão não faz nada quando eu clico. O console mostra este erro: [cole aqui]. Encontre a causa antes de mudar qualquer coisa.”
