1 Qual ferramenta usar, e quanto custa

Claude Code, Codex, Copilot CLI ou Cursor. Quanto cada um custa, as opções grátis e como pagar só pelo que usar.

⏱ 15 min

Por que ferramentas de IA custam dinheiro

Cada pedido que você manda roda um modelo de IA grande nos computadores de outra empresa, e isso custa dinheiro para ela. Por isso toda ferramenta tem um limite: um plano mensal, créditos que você paga conforme usa, ou um plano grátis com uma cota pequena.

A boa notícia: o que este curso ensina (o spec, os passos pequenos, a revisão, o Git, a publicação) funciona com qualquer uma dessas ferramentas. Só mudam a instalação, alguns comandos e o nome do arquivo de instruções, e as aulas em que isso importa têm uma aba para cada ferramenta.

⚠️
Os preços mudam

Conferidos em 28 de outubro de 2026, em dólares, sem impostos. Planos grátis e preços mudam com frequência, então confira a página oficial antes de pagar: Claude, Codex, Copilot, Cursor.

O curso é escrito com o Claude Code, a ferramenta principal. Quando uma aula diz “o Claude”, leia como “o seu agente”.

Pague só pelo que usar: Claude Code com créditos

Em vez de um plano mensal, você pode comprar créditos de API no Claude Console e pagar só pelos pedidos que fizer. Se você programa algumas horas por mês, pode sair mais barato que um plano.

  1. Crie uma conta em platform.claude.com e compre créditos em Settings > Billing > Buy credits. Os créditos vencem em um ano e não têm reembolso, então comece com pouco.
  2. Instale o Claude Code (próxima aula). Na tela de login, escolha a conta do Console e depois Sign in with your Console account.
  3. Enquanto trabalha, digite /usage para ver uma estimativa do quanto a conversa já custou. A conta de verdade fica no Console, onde você também pode definir um limite de gasto.

O que deixa a conta baixa:

  • /clear quando mudar de assunto. Cada pedido reenvia a conversa inteira, então uma conversa longa custa mais a cada mensagem.
  • Passos pequenos e um spec claro: menos correções, menos pedidos.
  • No dia a dia, um modelo mais barato: o /model deixa você escolher. O módulo do app com IA, no curso completo, mostra quanto custa cada modelo.
⚠️
Alguns recursos precisam de um plano

Alguns recursos do Claude Code só funcionam quando você entra com um plano do Claude, e não com créditos. No curso completo, é a integração com o navegador no módulo de revisão. Aquela aula também mostra um jeito de fazer à mão.

As opções grátis

Copilot CLI Free, se você não quer pagar nada. É um agente de terminal do GitHub, muito parecido com o Claude Code. Você precisa de uma conta no GitHub, de que vai precisar mais tarde de qualquer jeito para publicar seus projetos, então pode criar agora em github.com. O plano grátis inclui o agente no terminal, com uma cota mensal (o GitHub não diz quanto).

Cursor Free, se você prefere um editor com botões em vez do terminal. O Cursor é baseado no VS Code, e o agente fica num painel lateral. O plano grátis tem “pedidos limitados ao agente”, também sem número.

O Codex não é grátis no terminal. Mas se você já paga o ChatGPT Plus, o Codex vem incluído, sem custo extra.

Quando o limite grátis acaba

Os limites grátis são pequenos e não são publicados, então ele pode acabar no meio de um projeto. Nada se perde: o seu projeto está em arquivos no seu computador, e qualquer ferramenta continua a partir deles. As suas opções:

  • Esperar o limite renovar (o do Copilot renova todo mês).
  • Trocar de ferramenta por alguns dias. O spec e o código são só arquivos.
  • Pagar um mês só (US$ 10 no Copilot Pro, US$ 8 no Cursor Plus) e cancelar depois.
  • Comprar alguns dólares de créditos do Claude.

O melhor jeito de economizar é o próprio método do curso. Um spec claro e passos pequenos gastam muito menos pedidos que “faz um app para mim” seguido de vinte correções.

💡
Pensando em trocar de ferramenta? Use AGENTS.md

Mais adiante no curso, você vai escrever um arquivo com as regras do projeto para a IA. O Claude Code lê o CLAUDE.md, e as outras três leem o AGENTS.md. O Claude Code também lê o AGENTS.md quando não existe um CLAUDE.md. Então, se você acha que vai trocar de ferramenta, chame o arquivo de AGENTS.md desde o começo, e as quatro vão ler.
