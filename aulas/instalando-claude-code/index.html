2 Configurando o Claude Code do zero

Instale o Claude Code, converse com ele pela primeira vez e veja um app criado por IA rodando no seu navegador.

⏱ 15 min

O que você vai fazer nesta aula

No fim desta aula você vai ter o Claude Code instalado, vai ter feito seu primeiro pedido para ele e vai ter uma página criada por IA rodando no seu navegador.

O que é o Claude Code (em 30 segundos)

O Claude Code é um assistente de programação que roda no terminal. Diferente de um chat comum, ele consegue ler os arquivos do seu projeto, criar e editar código e rodar comandos, sempre pedindo sua permissão antes de mudar alguma coisa.

Pense nele como um colega programador muito rápido: você explica o que quer, ele faz, e você revisa. Quem decide é sempre você.

Antes de começar

Você vai precisar de:

  • Um computador com macOS, Windows ou Linux
  • O Claude Code com um plano pago do Claude (Pro ou Max) ou com créditos do Claude Console, ou uma das outras ferramentas da aula anterior
  • Um terminal aberto
💡
Nunca usou o terminal?

O terminal é só uma janela onde você digita comandos em vez de clicar. No Mac, aperte Cmd + Espaço e digite “Terminal”. No Windows, abra o menu Iniciar e digite “PowerShell”.

Esta aula usa o Claude Code. Se você escolheu outra ferramenta, escolha a aba dela nos passos abaixo. O site lembra a sua escolha em todas as aulas.

Passo 1: Instalar

Copie o comando do seu sistema, cole no terminal e aperte Enter. A aba do seu sistema já vem selecionada.

curl -fsSL https://claude.ai/install.sh | bash

O instalador não mostra progresso enquanto baixa. Espere ele terminar.

O Codex precisa do ChatGPT Plus ou de um plano maior (ou de uma chave de API da OpenAI). Copie o comando do seu sistema, cole no terminal e aperte Enter.

curl -fsSL https://chatgpt.com/codex/install.sh | sh

O Copilot CLI funciona com o plano grátis do Copilot. Você precisa de uma conta no GitHub: crie em github.com se ainda não tiver. Depois copie o comando do seu sistema, cole no terminal e aperte Enter.

curl -fsSL https://gh.io/copilot-install | bash

O Cursor é um editor, então você instala como qualquer app: baixe em cursor.com, instale com as opções padrão e abra. Ele é baseado no VS Code, então vai parecer familiar se você já viu o VS Code.

Passo 2: Conferir se funcionou

Abra uma nova janela do terminal (importante!) e rode:

claude --version

Se aparecer um número de versão seguido de (Claude Code), deu certo.

Abra uma nova janela do terminal (importante!) e rode:

codex --version

Se aparecer um número de versão, deu certo.

Abra uma nova janela do terminal (importante!) e rode:

copilot help

Se aparecer a lista de opções, deu certo.

Se o Cursor abriu, deu certo. Na primeira vez ele faz algumas perguntas (tema, atalhos de teclado): as opções padrão servem.

⚠️
Apareceu "command not found" ou "não é reconhecido"?

Feche o terminal e abra de novo. Se o erro continuar, o instalador não conseguiu adicionar o comando ao PATH do seu sistema. Para o Claude Code, o guia oficial de problemas de instalação tem a solução para cada erro. Para as outras ferramentas, pergunte na comunidade ou pesquise a mensagem de erro exata.

Passo 3: Sua primeira sessão

Crie uma pasta para o projeto, entre nela e abra o Claude Code:

mkdir meu-primeiro-app
cd meu-primeiro-app
claude

O que cada linha faz:

  • mkdir meu-primeiro-app cria uma pasta nova
  • cd meu-primeiro-app entra nessa pasta
  • claude inicia o Claude Code dentro dela

Na primeira vez, ele pede para você fazer login. Siga as instruções: o navegador abre, você entra na sua conta e volta para o terminal. Depois disso, não precisa logar de novo. Se você usa créditos em vez de um plano, escolha a conta do Console na tela de login.

Crie uma pasta para o projeto, entre nela e abra o Codex:

mkdir meu-primeiro-app
cd meu-primeiro-app
codex

Na primeira vez, escolha Sign in with ChatGPT: o navegador abre, você entra na sua conta e volta para o terminal.

Crie uma pasta para o projeto, entre nela e abra o Copilot CLI:

mkdir meu-primeiro-app
cd meu-primeiro-app
copilot

Na primeira vez, se ele disser que você não está logado, digite /login e siga os passos: você entra no GitHub pelo navegador e volta para o terminal.

No terminal, crie uma pasta para o projeto:

mkdir meu-primeiro-app

No Cursor, escolha File > Open Folder e abra a meu-primeiro-app. Depois abra o painel do agente com Cmd+I (Mac) ou Ctrl+I (Windows e Linux). Entre na sua conta quando o Cursor pedir.

Passo 4: Seu primeiro pedido

Com o Claude Code aberto (ou a sua ferramenta), copie e envie este pedido:

Crie um arquivo index.html com uma página que diga "Olá, mundo!" e um botão que muda a cor do fundo a cada clique. Use HTML, CSS e JavaScript simples, com comentários em português explicando o código.

O Claude vai mostrar o que pretende fazer e pedir sua permissão. Leia antes de aprovar. Se fizer sentido, escolha Yes.

Para abrir a página no navegador, peça ao próprio Claude (“abra o index.html no navegador”) ou rode, em outro terminal na mesma pasta:

open index.html      # macOS
start index.html     # Windows

Entendendo o que a IA fez

O código que o Claude escreveu deve ser parecido com o de baixo. Não vai ser idêntico: a IA quase nunca escreve exatamente igual duas vezes. Edite à vontade, o resultado aparece na hora:

Três desafios rápidos:

  1. Troque “Olá, mundo!” pelo seu nome (aba HTML).
  2. Adicione mais uma cor na lista cores (aba JavaScript). Dica: cores são escritas assim: '#ffb4a2'.
  3. Mude a cor do botão (aba CSS, procure background).

Se quebrar alguma coisa, clique em Recomeçar. Errar aqui não custa nada.

Quem manda é você

O Claude Code pede permissão antes de editar arquivos ou rodar comandos. No começo, aprove um passo de cada vez e leia o que ele vai fazer. Se não entender alguma coisa, pergunte antes de aprovar: “o que esse comando faz?”.

Comandos úteis para guardar:

Comando Onde O que faz
claude Terminal Abre o Claude Code na pasta atual
claude -c Terminal Continua a última conversa daquela pasta
/help Dentro do Claude Mostra os comandos disponíveis
/clear Dentro do Claude Limpa a conversa e começa do zero
/exit Dentro do Claude Sai do Claude Code
Comando Onde O que faz
codex Terminal Abre o Codex na pasta atual
codex resume Terminal Reabre uma conversa salva
/new Dentro do Codex Começa uma conversa nova
/status Dentro do Codex Mostra o modelo, as permissões e o uso
/quit Dentro do Codex Sai do Codex
Comando Onde O que faz
copilot Terminal Abre o Copilot CLI na pasta atual
copilot --continue Terminal Continua a última conversa
? Dentro do Copilot Mostra a ajuda
/clear Dentro do Copilot Começa uma conversa nova
/usage Dentro do Copilot Mostra quanto você já usou

No Cursor, tudo acontece no painel do agente (Cmd+I ou Ctrl+I). Quando mudar de assunto, comece um chat novo ali em vez de continuar um antigo.
