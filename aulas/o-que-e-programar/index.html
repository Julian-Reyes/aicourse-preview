0 O que é programar, e a linha de comando

O que é um programa, como é a cara do código e os poucos comandos de terminal que você precisa antes de instalar o Claude Code.

⏱ 15 min

Comece aqui se você nunca programou

Esta aula é para quem está começando do zero absoluto. Em 15 minutos você vai saber o que é um programa, como é a cara do código e como andar pelo seu computador no terminal, a janela onde o Claude Code mora. Se você já sabe tudo isso, pode pular para a próxima aula.

Um programa é uma lista de instruções

Um programa é uma lista de instruções que o computador segue em ordem, uma de cada vez, exatamente como estão escritas. Pense numa receita escrita para um robô: ele não adivinha o que você quis dizer e não pula etapas. Ele faz o que está escrito.

Cada linha abaixo é uma instrução: “mostre este texto”. O resultado aparece no console, embaixo do código, e se atualiza enquanto você digita.

Experimente

Instruções, em ordem

Console
Nada no console ainda. Use console.log(...) para mostrar valores aqui.

Desafios:

  1. Troque a primeira linha com a última. O computador segue a nova ordem sem reclamar, mesmo que ela não faça sentido.
  2. Acrescente uma quarta linha, console.log('Beba');, copiando o formato das outras.

O computador leva tudo ao pé da letra

Agora quebre alguma coisa de propósito: numa das linhas, troque console por consol. Aparece um erro em vermelho.

Um erro não é um desastre, e não estraga o seu computador. É o programa avisando “não entendi esta linha”. Ler o erro, ou copiar ele para a IA, é o primeiro passo para consertar. Quem programa vê erros o dia inteiro.

💡
Você não precisa decorar nada

Neste curso, a IA escreve a maior parte do código. O seu trabalho é dizer com clareza o que você quer, rodar o que ela fez e conferir se funciona. Para isso você precisa de três coisas: saber onde estão seus arquivos, saber rodar comandos e não entrar em pânico com um erro. É o resto desta aula.

Código é texto, guardado em arquivos

Código é só texto, guardado em arquivos. O fim do nome do arquivo (a extensão) diz que tipo de código tem dentro. Um site costuma ter três tipos:

Arquivo O que faz Numa casa, seria
index.html O que tem na página: títulos, textos, botões As paredes e os cômodos
style.css A aparência: cores, tamanhos, fontes A pintura e os móveis
script.js O que acontece: cliques, contas, mudanças A parte elétrica

Um projeto é uma pasta com todos os arquivos dele dentro. Quando você pede para o Claude Code construir um app, ele cria e edita arquivos dentro da pasta em que você está.

Arquivos moram em pastas, e pastas têm caminhos

O seu computador organiza tudo em pastas dentro de pastas. O caminho é o endereço de um arquivo: cada / entra uma pasta mais para dentro.

/Users/ana/Documents/meu-primeiro-app/index.html

Leia da esquerda para a direita: na pasta da usuária ana, dentro de Documents, dentro de meu-primeiro-app, está o arquivo index.html. O sinal ~ é um atalho para a sua pasta inicial, então o mesmo caminho pode ser escrito como ~/Documents/meu-primeiro-app/index.html.

O terminal: conversando com o computador por escrito

O terminal (também chamado de linha de comando) é uma janela onde você digita comandos em vez de clicar. Ele mostra os mesmos arquivos e pastas que você vê no Finder ou no Explorador de Arquivos, só que em texto.

Para abrir:

  • No Mac: aperte Cmd + Espaço, digite Terminal e aperte Enter.
  • No Windows: abra o menu Iniciar, digite PowerShell e aperte Enter.

Quando ele abrir, você vai ver uma linha assim, chamada de prompt:

ana@mac ~ %

Ela diz quem você é (ana), em qual computador, e em qual pasta você está (~, a sua pasta inicial). Você digita depois do % (no Windows, depois do >) e aperta Enter. A resposta aparece embaixo, e o prompt volta quando o comando termina.

Quatro comandos bastam para começar

Comando O que faz
pwd Mostra em qual pasta você está
ls Lista o que tem na pasta
cd nome Entra numa pasta. cd .. volta uma pasta para cima
mkdir nome Cria uma pasta nova

Pratique neste terminal de mentira. Nada que você digita aqui mexe no seu computador, então errar é de graça. Siga as missões:

Terminal de treino

Pratique sem medo: nada aqui mexe no seu computador

Digite um comando e aperte Enter. Digite help para ver a lista.
voce@mac ~ %
Missões
  1. 1Descubra em qual pasta você está: pwd
  2. 2Veja o que tem nela: ls
  3. 3Entre em Documents: cd Documents
  4. 4Crie uma pasta para o seu primeiro app: mkdir meu-primeiro-app
  5. 5Entre nela: cd meu-primeiro-app
  6. 6Confira onde você está agora: pwd
  7. 7Volte uma pasta para cima: cd ..

É exatamente isso que você vai fazer quando instalar o Claude Code: criar uma pasta para o projeto, entrar nela e abrir o Claude Code ali.

Três truques que economizam tempo

  • Tab completa nomes. Digite cd Doc e aperte Tab: o terminal completa para Documents.
  • A seta para cima traz de volta o último comando, sem precisar digitar de novo.
  • Ctrl + C interrompe um comando que ainda está rodando. Se o terminal parecer travado, essa é a saída.
💡
Nomes de pasta sem espaço

Use meu-primeiro-app em vez de Meu Primeiro App. Espaços no nome fazem o terminal achar que você digitou duas coisas separadas. Letras minúsculas e hífens nunca dão problema. Evite acentos também.
