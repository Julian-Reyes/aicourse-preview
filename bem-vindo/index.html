Por onde começar

O mini-curso grátis leva você do zero ao seu primeiro app publicado na internet, em 5 aulas curtas.

0 de 5 aulas concluídas
  1. 0O que é programar, e a linha de comandoO que é um programa, como é a cara do código e os poucos comandos de terminal que você precisa antes de instalar o Claude Code.15 min
  2. 1Qual ferramenta usar, e quanto custaClaude Code, Codex, Copilot CLI ou Cursor. Quanto cada um custa, as opções grátis e como pagar só pelo que usar.15 min
  3. 2Configurando o Claude Code do zeroInstale o Claude Code, converse com ele pela primeira vez e veja um app criado por IA rodando no seu navegador.15 min
  4. 3Seu primeiro SPEC.mdAprenda a escrever um spec, a lista curta que faz a IA construir o que você quer (e não o que ela imagina).15 min
  5. 4Do código ao ar: publicando no GitHub PagesColoque seu app na internet de graça, com um link para mandar para qualquer pessoa.20 min
