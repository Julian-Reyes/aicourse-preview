The web page, inside and out

HTML, CSS, and the browser's tools: what the page the AI builds is made of, and how to open and inspect it.

4 lessons · 90 min

Start the first lesson →See the lessons

What you'll build

Every project in this course is a web page. In this module you learn what it's made of: the HTML that gives it structure, the CSS that gives it its look, and how JavaScript connects to both. You also learn to open the project the right way and to use the browser's tools to see what's going on. You finish with a page of your favorite cafes, good-looking and working on phones.

  • Edit and see it liveHTML and CSS in an editor on the page: change a line and the page changes with it.
  • The tools developers useInspect elements, read errors in the console, and watch requests, like on a real job.
  • First lesson freeThe lesson on how a page is made is open so you can start.

What you'll learn

  • How HTML, CSS, and JavaScript come together in a page
  • Why a page sometimes stays blank, and how to open it with a local server
  • The HTML elements that show up in every app
  • Colors, spacing, flexbox, and pages that work on phones
  • Using DevTools to inspect, try out CSS, and find errors
