Your first app, start to finish

A cafe journal built with the spec method: versions with Git, data saved in the browser, and a live link.

5 lessons · 110 min

Tell me when it opensSee the lessons

What you'll build

Before the big projects, a small app from start to finish: a cafe journal where you note the places you've been, give them a rating, filter, and delete, and everything is still there when you reopen the page. You use the spec method, save every step with Git, understand the pattern behind almost every app, and finish with the app online, at a link that opens on any phone.

  • A whole app, smallYou finish it in one sitting, and it uses everything from the basics.
  • Git from the startEvery step saved as a version. If the AI breaks something, you go back in seconds.
  • The pattern of every appData, a function that draws the screen, and events that change the data. The same as in the big projects.

What you'll learn

  • Writing the spec for a small app and building it step by step
  • Saving versions with Git and undoing a bad change
  • Drawing the screen from a list of data
  • Forms, delete buttons, and filters
  • Keeping data in the browser with localStorage and JSON
  • Publishing it for free on GitHub Pages, with a link to share
