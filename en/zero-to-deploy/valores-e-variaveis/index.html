2.1 Values and variables, the labeled boxes

The kinds of value that show up in every app, how to keep a value under a name, the difference between const and let, and how to build text.

⏱ 15 min

Every program works with values

Everything an app keeps and shows is a value: the name of a cafe, a distance, whether it’s open or not. The three kinds you’ll see most:

  • Text (the AI calls it a string): always in quotes, like 'Café da Praça'.
  • A number: no quotes, like 42 or 0.2.
  • True or false (a boolean): true or false. Every comparison, like 5 > 3, gives one of the two.

Run the example. Each console.log shows a value in the console, below the code.

A variable is a labeled box

A variable keeps a value under a name, so you can use it later. Think of a box with a label: the label is the name, and what’s inside is the value.

const or let?

You may have noticed the example uses two words to create variables:

  • const for values that don’t change after they’re created, like the cafe’s name.
  • let for values that will change, like the number of visits.

The AI uses const almost always and let only when it has to. That helps when reading code: when you see let, you know that value changes somewhere.

What kind is it?

Sort it

Text, number, or true/false?

  • 'Ana'
  • 42
  • '42'
  • true
  • 'true'
  • 0.5
  • 5 > 3

Where you’ll see this in the course

  • In the 3D game, let passed = 0 counts how many rings you’ve flown through, and let start = performance.now() keeps the time the race started. They’re let because they change during the game.
  • In the map app, let you = [-18.9186, -48.2772] keeps your position (latitude and longitude). It changes when the browser finds out where you are.
  • In the AI app, the server keeps the kinds of photo it accepts in const ACCEPTED_TYPES. That list never changes while the app runs.
  • In the “Hello, world!” button, let index = 0 remembers which color the background is now.
💡
Good names are gold

A variable called x says nothing. One called minutesOnFoot says it all. When the AI writes confusing names, ask: “Rename the variables in this file to names that explain what they hold. Don’t change the behavior.” And when you don’t understand one: “What does the variable index hold, and where in the code does it change?”
