From Zero to Deploy · Module 1 · Lesson 1.1

What AI does (and doesn't do)

Learn where AI coding tools shine, where they go wrong, and what your role is in every project in this course.

⏱ 10 min

Why start here

In this course you’ll build four real apps with help from AI. Before you install anything, it’s worth having a clear idea of what to expect from it. People who expect magic get frustrated at the first error. People who understand how it works get much better results.

What AI does really well

  • Writing common code, fast. A page, a form, a button that saves data: things a programmer would spend an afternoon on, it does in minutes.
  • Explaining code. You can point at any snippet and ask “what does this do?”. It’s like having a patient teacher next to you.
  • Finding the cause of errors. Paste the error message and it usually knows where to start.
  • Suggesting approaches. “What’s the simplest way to show a map?” gets you good options, with pros and cons.
  • Doing repetitive work. Renaming things across files, translating text, creating sample data.

Where it goes wrong

  • It makes things up, confidently. Sometimes it uses a function that doesn’t exist or mentions an option that never existed. The technical name is hallucination. The code looks right, but it doesn’t run.
  • Its knowledge has a date. Libraries change. The AI may suggest an old way of doing something.
  • It can’t read minds. If you don’t say what you want, it guesses. And it tends to guess too big.
  • It doesn’t care about security unless you ask. Putting a secret key straight into a website’s code is a classic AI mistake (you’ll see this in module 5).
  • “Looks right” isn’t “is right”. Only testing tells you.

Your role: product owner and reviewer

Think of it as a division of labor:

You The AI
Decide what to build and why Proposes how to build it
Write the spec (module 2 teaches this) Writes the code following the spec
Test in the browser and on your phone Fixes what you describe
Check security and costs Explains what it did when you ask
💡
This applies to the whole course

In every project, you’ll follow the same loop: describe → the AI builds → you test → adjust. The better you describe and test, the better the result.

Sort it

Who does it better: the AI or you?

  • Writing 200 lines of HTML for a contact page
  • Deciding which features the app needs
  • Explaining what a piece of code does
  • Checking that the button works on your phone
  • Making sure no secret key was left in the website code
  • Finding the cause of an error message
Checkpoint

Check what you learned

  1. The AI used a function that doesn't exist and the code won't run. What is this called?

  2. What is your main role when coding with AI?

  3. The code the AI wrote "looks right". What do you do?
