From code to online: publishing on GitHub Pages

Put your app on the internet for free, with a link you can send to anyone.

⏱ 20 min

What you’ll do in this lesson

Put my-first-app online, for free, with a link like your-username.github.io/my-first-app that opens on any phone.

Three words to know

  • Git keeps the version history of your project, on your computer. Each saved version is called a commit, like a snapshot of the project at that moment.
  • GitHub is a website that keeps a copy of the project in the cloud.
  • GitHub Pages is a free GitHub service that turns that copy into a public website.

Before you start

  • Create a free account at github.com if you don’t have one.
  • Check that Git is installed:
git --version

On a Mac, if it isn’t installed, the system offers to install the developer tools: accept. On Windows, install Git for Windows.

⚠️
Everything on GitHub Pages is public

Anyone can see your site’s files. Never put API keys, passwords, or personal data in them. Module 5 of the full course covers the safe way to use API keys.

Step 1: Save a version with Git

Open Claude Code in the project folder and ask:

Initialize a Git repository in this folder and make the first commit with all the files. Explain every command you run.

Read the explanations. You don’t need to memorize the commands, but you do need to know what each one does.

Step 2: Send it to GitHub

Pick one of these two paths.

Path A: through the GitHub website

  1. On GitHub, click New repository.
  2. Name: my-first-app. Select Public. Don’t add a README.
  3. Click Create repository and copy the address it shows (it ends in .git).
  4. In Claude Code, ask:
Connect this repository to GitHub at https://github.com/YOUR-USERNAME/my-first-app.git and push the code to the main branch.

Replace YOUR-USERNAME with your GitHub username. If it asks you to log in and your password doesn’t work, that’s normal: GitHub no longer accepts passwords from the terminal. Use Path B, which takes care of logging in.

Path B: with the GitHub CLI (faster)

Install the GitHub CLI, log in once, and create the repository with a single command:

gh auth login
gh repo create my-first-app --public --source=. --push

Step 3: Turn on GitHub Pages

  1. In your repository on GitHub, open Settings.
  2. In the sidebar, click Pages.
  3. Under Build and deployment, choose Source: Deploy from a branch.
  4. Select the main branch and the / (root) folder. Click Save.
  5. Wait a minute or two and reload the page. Your site’s link appears at the top.
💡
The home page must be called index.html

GitHub Pages looks for a file named exactly index.html at the root of the project. If yours has a different name, ask Claude to rename it.
