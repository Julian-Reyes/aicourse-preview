1 Which tool, and what it costs

Claude Code, Codex, Copilot CLI, or Cursor. What each one costs, the free options, and how to pay only for what you use.

⏱ 15 min

Why AI tools cost money

Every request you send runs a large AI model on someone else’s computers, and that costs the company money. So every tool has a limit: a monthly plan, credits you pay for as you go, or a free plan with a small allowance.

The good news: what this course teaches (the spec, small steps, reviewing, Git, publishing) works with any of these tools. Only the install, a few commands, and the name of the instructions file change, and the lessons where that matters have one tab per tool.

Prices change

Checked on October 28, 2026, in US dollars, before taxes. Free plans and prices change often, so check the official page before you pay: Claude, Codex, Copilot, Cursor.

The course is written with Claude Code, the main tool. When a lesson says “Claude”, read it as “your agent”.

Pay only for what you use: Claude Code with credits

Instead of a monthly plan, you can buy API credits in the Claude Console and pay only for the requests you make. If you code a few hours a month, it can come out cheaper than a plan.

  1. Create an account at platform.claude.com and buy credits in Settings > Billing > Buy credits. Credits expire after a year and can’t be refunded, so start small.
  2. Install Claude Code (next lesson). At the login screen, choose the Console account, then Sign in with your Console account.
  3. While you work, type /usage to see an estimate of what the conversation has cost so far. The real bill is in the Console, where you can also set a spend limit.

What keeps the bill low:

  • /clear when you change topics. Every request resends the whole conversation, so a long one costs more with each message.
  • Small steps and a clear spec: fewer corrections, fewer requests.
  • For everyday work, a cheaper model: /model lets you choose. The full course’s AI app module shows how much each model costs.
⚠️
A few features need a plan

Some Claude Code features only work when you log in with a Claude plan, not with credits. In the full course, that’s the browser integration in the review module. That lesson also shows a way to do it by hand.

The free options

Copilot CLI Free, if you want to pay nothing. It’s a terminal agent from GitHub, very similar to Claude Code. You need a GitHub account, which you’ll need later anyway to publish your projects, so you can create it now at github.com. The free plan includes the terminal agent, with a monthly allowance (GitHub doesn’t say how much).

Cursor Free, if you’d rather use an editor with buttons than the terminal. Cursor is based on VS Code, and the agent lives in a side panel. The free plan has “limited agent requests”, also without a number.

Codex isn’t free in the terminal. But if you already pay for ChatGPT Plus, Codex is included, with no extra cost.

When the free limit runs out

The free limits are small and not published, so you may run out in the middle of a project. Nothing is lost: your project is in files on your computer, and any tool can continue from them. Your options:

  • Wait for the limit to reset (Copilot’s resets every month).
  • Switch tools for a few days. The spec and the code are just files.
  • Pay for one month only (US$10 for Copilot Pro, US$8 for Cursor Plus) and cancel afterwards.
  • Buy a few dollars of Claude credits.

The best way to save is the course method itself. A clear spec and small steps use far fewer requests than “build me an app” followed by twenty corrections.

💡
Thinking of switching tools? Use AGENTS.md

Later in the course, you’ll write a file with your project’s rules for the AI. Claude Code reads CLAUDE.md, and the other three read AGENTS.md. Claude Code also reads AGENTS.md when there’s no CLAUDE.md. So if you think you’ll switch tools, name the file AGENTS.md from the start, and all four will read it.
